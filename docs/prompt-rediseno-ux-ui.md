# Prompt: Rediseño UX/UI de ERP — Propiedad Raíz

## Contexto del prompt

Este prompt fue construido para solicitar el rediseño completo de la interfaz visual (UI) y la experiencia de usuario (UX) de un sistema ERP hipotético, orientado al rubro de **propiedad raíz**, basado en las mejores prácticas de los ERPs líderes a nivel mundial.

---

## Prompt

Actuá como un diseñador UX/UI senior con más de 50 años de experiencia, experto mundial en el diseño de sistemas ERP. Basá tus decisiones en los principios y patrones de los 5 mejores ERPs del mundo en cuanto a UX/UI (Workday, Oracle Fusion Cloud, NetSuite, SAP S/4HANA con su sistema Fiori, y Acumatica), combinando lo mejor de cada uno según corresponda.

Tu tarea es rediseñar por completo la interfaz visual y la experiencia de usuario de un ERP para una empresa del rubro de **propiedad raíz (bienes raíces)**. El sistema debe estar pensado para una mezcla de todo tipo de roles: personal sin experiencia técnica, personal administrativo y directivos/gerentes.

No existe un diseño previo — partí desde cero, de forma hipotética, proponiendo la mejor estructura posible.

Para cada decisión de diseño (navegación, jerarquía de información, tablas de datos, sistema de colores, formularios, prevención de errores, etc.), explicá:

1. Qué decisión tomarías
2. Por qué la tomarías (basado en principios de UX/UI reales)
3. Cómo beneficia específicamente a un ERP de propiedad raíz y a la mezcla de usuarios mencionada

Entregá el resultado en dos formatos:

- Una **comparativa antes/después** conceptual (cómo sería un ERP típico sin buen diseño vs. tu propuesta)
- Una **guía paso a paso de implementación**, ordenada por prioridad

Además, generá mockups o imágenes visuales de referencia que ilustren cómo se vería el diseño final (dashboard, módulo de propiedades, formularios, etc.).

Respondé en español, con un nivel de detalle extenso, explicando el razonamiento detrás de cada decisión de diseño.

---

## Parámetros usados en la construcción

| Parámetro | Valor |
|---|---|
| Alcance | Todo el sistema ERP en general |
| Usuarios | Mezcla de todos los roles |
| Rubro | Propiedad raíz |
| Estado actual | Hipotético (sin diseño previo) |
| Referencias | Workday, Oracle Fusion, NetSuite, SAP Fiori, Acumatica (combinados) |
| Idioma de respuesta | Español |
| Nivel de detalle | Extenso, con justificación de cada decisión |
| Formato de salida | Comparativa antes/después + guía de implementación + mockups visuales |
